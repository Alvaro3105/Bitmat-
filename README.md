# Bitmap Photography — Projeto Front-end

Projeto acadêmico de front-end inspirado em um site de fotografia, desenvolvido para praticar construção de páginas com **HTML e CSS**.

## Tecnologias

- HTML5
- CSS3

## Páginas

O projeto possui páginas como:

- Home (`index.html`)
- About (`about.html`)
- Services (`services.html`)
- Contact (`contact.html`)

## O que o projeto pratica

- navegação entre páginas;
- layout de landing page;
- galerias e blocos visuais;
- formulários;
- composição com imagens;
- estilização responsiva.

## Como executar

1. Clone o repositório.
2. Abra `index.html` no navegador.

## Contexto

Projeto criado durante a formação técnica em TI como exercício de HTML e CSS.
